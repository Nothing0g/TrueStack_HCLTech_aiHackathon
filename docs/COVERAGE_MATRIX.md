# DTU Source Coverage Matrix

**Corpus status:** The full local bundle includes the three supplied official DTU PDFs and the complete OCR-derived text sidecar for the 143-page B.Tech Ordinance. The public Git repository omits the large original PDFs and includes a focused ordinance excerpt for the cited demo clauses, alongside page-anchored text for the one-page 2026–27 examination notice and seven-page placement policy. OCR can contain errors; verify cited clauses visually in the original PDF before relying on them for real academic decisions.

## Synthetic demo sources

Exactly two synthetic documents are bundled to demonstrate a baseline rule and a later circular that supersedes that baseline, plus a lower-authority contradictory FAQ. They are labelled **SYNTHETIC DEMO — NOT OFFICIAL DTU POLICY**. The synthetic amendment supersedes only the synthetic baseline clause, never the real DTU ordinance. Synthetic placement and supplementary rules are for showcasing tool execution only and must display a synthetic badge in the UI and citations.

## Coverage limitations

- The Placement Policy is explicitly for the 2025–26 passing-out batch; do not silently generalise its cohort scope.
- The scanned ordinance OCR is searchable but may contain transcription errors. The cited original PDF is the human verification source.
- The base attendance rule does not capture automatic exceptions; condonation requires specific authorised grounds.
- The system must abstain from any policy answer not supported by retrieved authorised text.
